
# Ice Cream Shop Revenue Prediction

## Overview
This project implements a revenue prediction model for an ice cream shop based on temperature using linear regression. The model predicts the revenue generated based on the temperature input provided by the user. A Flask web application is created to allow users to input temperature and receive revenue predictions.

![Screenshot of the Application](Screenshot%202025-02-11%20135611.png)

## Repository Structure
- `IceCreamData.csv`: The dataset used for analysis.
- `main.py`: Python script for data preprocessing and analysis.
- `ml.ipynb`: Jupyter Notebook containing the machine learning model development.
- `model.pkl`: Pickle file for the trained machine learning model.
- `requirements.txt`: List of dependencies required to run the project.
- `static/`: Directory containing static files.
- `templates/`: Directory containing HTML templates.
  
## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Pickle

## Dataset
The dataset used in this project is `IceCreamData.csv`, which contains the following columns:
- `Temperature`: The temperature in degrees Celsius.
- `Revenue`: The revenue generated by the ice cream shop at that temperature.
  
## Installation
To install the required dependencies, run:
```bash
pip install -r requirements.txt
```

## Usage

### Model Training
The model is trained using the `ml.ipynb` Jupyter notebook. The steps include:
1. Loading the dataset.
2. Splitting the data into training and testing sets.
3. Training a linear regression model.
4. Saving the trained model as `model.pkl` using Pickle.

### Running the Flask Application
1. Ensure that the `model.pkl` file is in the same directory as `main.py`.
2. Run the Flask application by executing the following command in your terminal:
   ```bash
   python main.py
    ```
### Accessing the Application
Open your web browser and go to `http://127.0.0.1:5000/` to access the application.

### Making Predictions
1. Enter the temperature in the input field on the web application.
2. Click the "Submit" button to see the predicted revenue generated at that temperature.

### Example
After entering a temperature value, the application will display the predicted revenue generated by the ice cream shop.
